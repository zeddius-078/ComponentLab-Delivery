# 布局生成上手指南

本项目把同一设计版本的 Pixso HTML 和 DSL 合并为 Qt 页面。HTML 提供浏览器实测布局，DSL 提供节点层级、组件身份、实例属性和 Token 引用。项目只维护 HTML + DSL 路线。

## 校验组件 SDK

```powershell
pwsh -File Source/Verify-GeneratedComponentSDK.ps1
```

构建默认直接读取同级 `DesignToCode_GenerateComponent/build/sdk`。外部工作区可通过 `GENERATED_COMPONENT_SDK_ROOT` 指向同一权威发布目录。本项目不复制 SDK。

## 正式生成

```powershell
pwsh -File Source/HtmlDsl/Generate.ps1 `
  -CaptureManifest '<capture.json>' `
  -MappingDirectory '<Compact映射目录>' `
  -Font '<字体文件>' `
  -Batch '<批次>' `
  -Page '<页面工程名>'
```

输出进入 `build/delivery/<批次>/<页面>`。正式页面包含 `.ui/.h/.cpp/.qss`；页面需要本地资源时附带 QRC。

## 验证

```powershell
python -B Source/Validation/check_delivery.py --formal-batch '<批次>'
pwsh -File Source/Validation/formal/Verify-RelocatedConsumer.ps1 -Batch '<批次>' -SdkRoot '<SDK目录>'
```

历史 V2 预览需要显式传 `-Preview`。未映射组件会终止生成，并返回节点与缺失映射；组件实现应在 GenerateComponent 补齐后重新发布 SDK。

`Source/HtmlDsl`、`Source/Qt` 和 `Source/Validation` 共同构成布局生成工具链。工具链输出页面四件套与演示程序，不发布组件库或第二套 SDK。
