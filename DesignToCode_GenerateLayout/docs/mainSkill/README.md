# Skill 入口

布局生成任务从 [generate-layout-pipeline/SKILL.md](generate-layout-pipeline/SKILL.md) 开始，先按 HTML＋DSL 或原生 Vue 附件选择路线。两条路径的输入合同、实现、工作目录与验收证据不能混用。

原生 Vue 静态转换的参数、映射、图标回退与当前限制统一维护在[第二路径说明](../Pixso原生DSM-D2C到Qt第二路径说明.md)，不在 Skill 复制历史测试过程或承诺尚未发布的离线能力。

工具、依赖和固定环境见[上手指南](../tutorial/布局生成上手指南.md)。公共环境约束见工作区根 `AGENTS.md`。
