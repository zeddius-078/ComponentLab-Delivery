# Qt 表格设计与页面映射

## 适用范围

本文说明设计侧表格、列表和数据区域如何进入 Qt 页面。组件身份来自 GenerateComponent 的 SDK；本项目负责页面结构、实例属性、列行关系和页面资源。

## 输入

| 输入 | 内容 | 来源 |
| --- | --- | --- |
| HTML | 页面实际渲染尺寸、文字测量和可见结构 | D2C 采集结果 |
| DSL | 节点树、实例身份、属性、状态和 Token 引用 | Pixso MCP 原始响应整理结果 |
| 组件合同 | 组件 canonical ID、Qt 类、公开属性 | GenerateComponent SDK manifest |
| 页面映射 | 业务字段与表格列、操作入口的对应关系 | 页面输入目录 |

## 生成规则

1. 先识别表格容器，再识别表头、数据行、单元格和操作区域。
2. 每个可交互节点使用已登记的 `Z_*` 组件；没有合同的节点记录缺失并停止正式生成。
3. 行列、跨度、间距和对齐写入布局模型；颜色、字体和状态交给 SDK Token/QSS。
4. 业务数据、排序、筛选和分页属于业务 Qt 工程，页面包只保留结构和初始展示值。
5. 输出的 objectName 由稳定节点名生成，并在页面内唯一。

## 输出与验证

页面输出 `.ui/.h/.cpp/.qss/.qrc`。验证顺序为：组件合同检查、布局结构检查、`uic` 解析、消费者编译、运行检查和视觉检查。表格数据为空、列缺失或组件身份未登记时，报告具体节点和字段。
