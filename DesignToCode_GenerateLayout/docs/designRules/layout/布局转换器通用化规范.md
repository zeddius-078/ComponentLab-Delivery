# 布局转换器通用化规范

## 目标

布局转换器把设计侧布局合同转换为 Qt 布局对象，再序列化为 `.ui`：

```text
设计布局 -> layout-mapping.json -> LayoutConverter -> QLayout -> .ui -> uic
```

统一接口返回 `QLayout*`，具体类型由布局语义决定。

| 设计值 | Qt 类型 | 必要定位信息 |
| --- | --- | --- |
| `HORIZONTAL` | `QHBoxLayout` | 子项顺序、间距、对齐 |
| `VERTICAL` | `QVBoxLayout` | 子项顺序、间距、对齐 |
| `GRID` | `QGridLayout` | 行、列、行跨度、列跨度 |
| `FORM` | `QFormLayout` | 行号、Label/Field/Spanning 角色 |

## 实现位置

| 文件 | 作用 |
| --- | --- |
| `docs/fixtures/layout/mapping/layout-mapping.json` | 登记布局值域和字段 |
| `Source/HtmlDsl/pipeline/engines/layout_converter/LayoutConverter.h/.cpp` | 创建布局、校验字段、加入子项 |
| `Source/HtmlDsl/pipeline/compiler/SceneBuilder.cpp` | 将节点树交给布局转换器 |
| `Source/HtmlDsl/pipeline/compiler/UiCompiler.cpp` | 输出 `.ui` XML |

| `docs/validation/layout/test_shape_matrix.py` | 结构、定位和重复生成检查 |

## 类型分派

```text
HORIZONTAL -> QHBoxLayout
VERTICAL   -> QVBoxLayout
GRID       -> QGridLayout
FORM       -> QFormLayout
```

Box 使用 `addWidget(widget, stretch, alignment)`。Grid 使用 `addWidget(widget, row, column, rowSpan, columnSpan, alignment)`。Form 使用 `setWidget(row, role, widget)`。返回类型统一不改变各子类的定位 API。

## Grid

子项必须提供非负整数 `gridRow`、`gridColumn`。`gridRowSpan` 和 `gridColumnSpan` 默认值为 `1`，显式值必须大于等于 `1`。重复占用单元格返回 `GRID_CELL_OVERLAP`。行列拉伸写入 `setRowStretch` 和 `setColumnStretch`，间距分别使用 `gridRowGap` 与 `gridColumnGap`。

```json
{"gridRow":0,"gridColumn":1,"gridRowSpan":1,"gridColumnSpan":2}
```

## Form

子项必须提供非负整数 `formRow` 和角色：

| 设计角色 | Qt 角色 | XML 列 |
| --- | --- | --- |
| `label` | `LabelRole` | `0` |
| `field` | `FieldRole` | `1` |
| `spanning` | `SpanningRole` | `0`，跨两列 |

同一行同一角色只能出现一次。`SpanningRole` 表达表单行跨越标签和字段两列，不能使用 Grid 的任意跨度规则。字段增长策略和换行策略按 `QFormLayout` 的枚举写入。

## 通用属性

四边边距、默认间距、尺寸策略和对齐适用于所有布局。绝对坐标不转换为布局定位。缺少 Grid/Form 专属字段、未知布局类型、非法跨度和重复占用必须返回明确错误。

## 验证矩阵

| 场景 | 检查 |
| --- | --- |
| Box 回归 | 顺序、间距、边距、伸缩和对齐 |
| Grid | 非连续行列、跨行跨列、行列伸缩 |
| Form | 三种角色、行号和增长策略 |
| 嵌套 | Box、Grid、Form 的混合层级 |
| 异常 | 缺字段、非法跨度、未知类型和重复占位 |

生成器先创建运行时布局并写出 trace，再输出 `.ui`，最后由 `uic` 和结构矩阵验证。重复输入应产生相同字节内容。
