# 布局生成执行与验收规则

## 生成链路

```text
捕获清单
  -> HTML + DSL 校验
  -> 浏览器适配与测量
  -> 组件身份映射
  -> 布局转换
  -> .ui/.h/.cpp/.qss/.qrc
  -> uic / 消费者编译 / 运行
```

HTML 和 DSL 必须来自同一设计版本。清单保存路径、根节点、文件标识、资源、字体、布局证据和哈希。正式模式需要独立的 `layoutReference`。

## 规则

1. 生成器只消费现有 SDK、映射合同和显式输入。
2. 页面结构进入 `.ui`；公共组件样式和 Token 进入 SDK；页面专属样式进入页面 `.qss`。
3. 运行时属性按组件公开 API 生成到 `.cpp`，不复制组件实现。
4. 未登记组件、未知布局、缺失定位字段和哈希不匹配直接失败。
5. 每个批次使用独立输出目录，已有页面目录拒绝覆盖。

## 验收表

| 阶段 | 实际检查 | 结果文件 |
| --- | --- | --- |
| capture | 文件、根节点、资源和哈希 | capture 报告 |
| adapt | HTML 渲染、字体和受支持布局测量 | adapter 报告 |
| generate | 组件、布局和页面文件生成 | 页面包 |
| uic | Qt XML 可解析 | uic 输出 |
| consumer | 头文件、库、QRC 和页面可编译 | 构建日志 |
| runtime | 页面可启动、属性可见 | 运行日志 |
| visual | 与设计版本的视觉比对 | 人工或自动证据 |

阶段结果分开记录。`PASS` 只适用于实际执行过的阶段。
