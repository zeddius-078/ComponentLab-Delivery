# ComponentLab 上手指南

## 1. 校验 SDK

```powershell
pwsh -File Source/Verify-GeneratedComponentSDK.ps1
```

校验内容包括发布者、配置、Qt 版本、架构、CRT、manifest 文件列表和逐文件 SHA-256。校验通过后，展示项目使用同一份 SDK。

## 2. 构建与运行

```powershell
pwsh -File Source/delivery/tools/Build.ps1
```

工作区构建优先使用根入口：

```powershell
pwsh -File Source/Workspace.ps1 -Action build -Target gallery
```

展示程序使用 SDK 内的组件实现、QSS、Token 资源和映射清单。组件页按 Button、Checkbox、Input、Select 及其他已登记组件族组织。

## 3. 查看一个组件

1. 进入组件族页。
2. 选择外观、尺寸、状态或 Profile。
3. 查看画布中的视觉结果和右侧对象树。
4. 在注册信息页核对设计身份、Qt 类、SDK 头文件和 Token 路径。

对象树用于说明组件内部结构；它来自公开组件运行时对象，不替代设计源数据。

## 4. 修改入口

| 需求 | 修改位置 |
| --- | --- |
| 组件视觉或状态 | GenerateComponent 的 Contract、Recipe、Token 或组件源码 |
| 展示页布局和导航 | `Source/delivery/demo` |
| 展示回归 | `Source/delivery/tests` |
| 展示运行依赖 | `Source/delivery/tools` |

ComponentLab 中的修改不能写入 SDK，也不能复制一套组件实现。

## 5. 验收边界

至少记录 SDK 校验、展示程序构建、目标组件交互和所选 Profile。截图只说明当前展示结果；SDK 消费测试负责确认业务工程能够通过公开头文件和 CMake 目标接入组件。
