# ComponentLab 上手指南

ComponentLab 导入 GenerateComponent 发布的 SDK，展示 `Z_*` 组件的外观、状态、Profile 和对象树。组件源码、Token 编译器和 QSS 生成逻辑由 GenerateComponent 维护。

## 校验 SDK

```powershell
pwsh -File Source/Verify-GeneratedComponentSDK.ps1
```

校验脚本检查发布者、manifest 和逐文件哈希。构建默认直接读取同级 `DesignToCode_GenerateComponent/build/sdk`，不向 ComponentLab 复制 SDK；外部工作区可设置 `GENERATED_COMPONENT_SDK_ROOT`。

## 构建与检查

```powershell
pwsh -File Source/delivery/tools/Build.ps1
python -B Source/delivery/tools/CheckProject.py
pwsh -File Source/delivery/tools/Verify.ps1
```

离线程序位于 `build/demo/component_gallery`。测试和验证报告位于 `build/reports`。

## 修改入口

| 目标 | 位置 |
| --- | --- |
| 新增组件导航和展示页 | `Source/delivery/demo` |
| 调整演示主题、图标和组合控制 | `Source/presentation` |
| 增加外观、状态或目录边界测试 | `Source/delivery/tests` |
| 修改构建、检查或打包 | `Source/delivery/tools` |

组件缺少属性、状态或 Token 时，回到 GenerateComponent 修改并重新发布 SDK；ComponentLab 不在本地补第二套组件实现。
