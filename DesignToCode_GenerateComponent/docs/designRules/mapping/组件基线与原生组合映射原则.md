# 组件基线与原生组合映射原则

## 目标

建立设计组件与 Qt 组件之间稳定、可检查的映射。Qt 原生能力提供实现基础，设计合同提供身份、属性、状态和视觉要求，SDK 提供业务工程可消费的公开组件。

## 资料来源

| 来源 | 用途 |
| --- | --- |
| Qt 5.15.2 元对象和官方 API | 类、属性、枚举、信号和可序列化能力 |
| Ant Design | 组件语义、状态和交互范围参考 |
| Figma/Pixso 设计文件 | 组件身份、变量绑定、实例属性和布局 |
| 项目 Token 源 | 颜色、字体、尺寸、圆角、状态和主题 |

外部资料提供语义参照，项目合同和实测 Qt 能力决定最终映射。

## 映射模型

```json
{
  "id": "qt.widgets.QPushButton",
  "qtClass": "QPushButton",
  "baseClass": "QAbstractButton",
  "category": "button",
  "mappingKind": "visual-component",
  "sdkClass": "commonWidget::Z_PushButton",
  "designComponent": "ComponentLab/Button",
  "owner": "GenerateComponent"
}
```

属性按落点登记：

| 类型 | 例子 | 落点 |
| --- | --- | --- |
| 设计变体 | intent、appearance、size | 设计 Variant、Registry |
| 实例属性 | text、placeholder、checked | `.ui` 或运行时 API |
| Token 属性 | color、font、height、radius | Token、QSS、组件主题 |
| 结构属性 | margin、spacing、stretch | Layout 和 `.ui` |
| 运行状态 | hover、pressed、focus、loading | Qt 事件和组件状态 |
| 业务数据 | options、model、selection | Controller/Model |

## Qt 包装组件

具体可视控件使用 `Z_` 前缀包装或提升：

```text
QPushButton → Z_PushButton
QCheckBox   → Z_CheckBox
QLineEdit   → Z_InputField
QComboBox   → Z_Select
```

每个公开类提供 parent 构造函数、公开属性、强类型枚举、Token/QSS 接口、工厂注册和 SDK 头文件。布局、Model、Validator 和全局应用对象登记能力后由页面或业务层消费。

## 验收

每个映射项要能追溯到设计身份、Qt 类、SDK 类、属性和值域。组件源码、QSS、头文件、注册信息和独立消费测试齐全后，才可进入 ComponentLab 和 GenerateLayout。
