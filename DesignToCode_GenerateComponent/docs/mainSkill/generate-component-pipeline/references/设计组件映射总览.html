3. 一个按钮的完整对应关系

ComponentLab/Button → 设计实例 submitButton → 登记族 Button → commonWidget::Z_PushButton

Label → setText；Type → setType；Size=M → setSize(M)；State=Disabled → setEnabled(false)。运行时的 Hover、Pressed 和键盘焦点由 Qt 事件驱动。

图标使用实例交换属性。登记表把图标主组件身份映射到 QRC 资源键；独立 IconButton 保留 accessibleName 和 Loading。

5. Figma 与 Pixso 的入口

Figma 使用 MCP 实例快照和项目登记表。Pixso 使用 DSM 别名与 D2C+ 解析配置，再转换到同一 UI Contract。DSM 属于 Pixso；Qt 适配层属于本项目。

模型负责调用读取工具、执行规则、运行校验与编译。新的组件类型或视觉能力需要设计与开发明确扩展登记表和组件实现。
