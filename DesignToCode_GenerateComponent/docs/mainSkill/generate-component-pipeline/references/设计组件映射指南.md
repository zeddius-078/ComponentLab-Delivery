# 设计组件映射指南

## 输入与负责人

| 输入 | 产生方 | 作用 |
| --- | --- | --- |
| 设计节点和变量 | Figma/Pixso MCP | 提供身份、层级、属性和变量绑定 |
| Token 源 | GenerateComponent | 提供原子、语义、主题和组件值 |
| Qt 能力目录 | Qt 5.15.2 扫描工具 | 提供类、属性和枚举 |
| 映射合同 | GenerateComponent | 连接设计组件与 Qt SDK 类 |

## 组件身份

设计侧记录 `fileKey`、`pageId`、`nodeId`、`componentSetId`、`componentKey` 和 `variantProperties`。开发侧记录 Qt 基类、SDK 类、公开头文件、CMake target 和组件注册名。

```text
ComponentLab/Button
    → componentSetId / componentKey
    → registry button
    → commonWidget::Z_PushButton
    → MyDesignSystem/Z_PushButton.h
```

## 属性与状态

设计属性进入 Registry 或 Contract。颜色、字号、圆角和尺寸绑定 Token；hover、pressed、focused、disabled、loading 进入状态合同；文本、图标和选项作为实例属性或运行时数据。

## Button 例子

```json
{
  "component": "button",
  "variant": {"intent": "primary", "appearance": "solid", "size": "md"},
  "state": "default",
  "tokenBindings": {
    "container.background": "semantic.color.action.primary.default",
    "content.color": "semantic.color.text.onAction"
  },
  "sdkClass": "commonWidget::Z_PushButton"
}
```

生成器根据合同写入组件 Token、QSS、头文件、实现文件、注册信息和 SDK manifest。页面生成器只消费公开 SDK，不重新生成 Button。

## 开发项目消费

```cpp
#include <MyDesignSystem/MyDesignSystem.h>
auto *button = new commonWidget::Z_PushButton(parent);
button->setText(QStringLiteral("确认"));
```

业务工程链接 `GeneratedComponentSDK::Components`。页面 `.ui` 可以声明提升类；页面 `.cpp` 只设置合同明确要求的运行时属性。

## 验收

映射测试检查设计身份、Token 路径、SDK 类名、头文件、公开 API 和状态值域。构建测试检查 C++ 消费；ComponentLab 检查视觉和对象树；GenerateLayout 检查页面装配。
